# Index3dex - Features & User Guide

## User Features

### 1. Authentication
- Secure registration and login
- JWT token-based authentication
- Session management with token expiration

### 2. Dashboard
- Real-time wallet balance display
- Available balance for investments
- Total invested amount tracking
- Earnings overview
- Quick action buttons

### 3. Investment Plans
- 7 different investment tiers (₦3,000 to ₦120,000)
- 5% daily returns (estimated)
- 30-day investment period
- Instant plan purchase
- Active investment tracking with countdown timers
- Daily earnings progress visualization

### 4. Wallet Management
- View real-time balance
- Request deposits (admin approval required)
- Request withdrawals with validation
- Complete transaction history
- Status tracking for each transaction

### 5. Referral System
- Unique referral code per user
- Shareable referral link
- Referral count tracking
- Referral earnings monitoring
- View referred users list

### 6. Profile Management
- Edit personal information
- Update contact details
- Manage bank account information
- Account security settings
- Profile picture (optional)

### 7. Support System
- Create support tickets
- Track ticket status
- Receive admin responses
- Message-based communication
